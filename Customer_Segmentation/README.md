# Mall Customer Segmentation

## Project Overview
This project performs customer segmentation using unsupervised machine learning techniques. It applies K-Means, Hierarchical Clustering, and DBSCAN to identify customer groups based on Age, Annual Income, and Spending Score.

## Dataset
- Dataset: Mall Customer Segmentation Dataset

## Algorithms Used
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN

## Evaluation Methods
- Elbow Method
- Silhouette Score
